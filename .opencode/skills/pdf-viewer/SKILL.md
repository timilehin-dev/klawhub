# PDF Viewer (v1.1.0)

View and interact with PDF documents directly in chat. Opens PDFs as readable content with navigation support.

## Commands

### /pdf-viewer:view-pdf
Open a PDF document for viewing. Supports any PDF file accessible in the workspace. Once opened, you can ask questions about the content, request summaries, extract specific information, or navigate to different sections.

**Usage**: `/pdf-viewer:view-pdf <path>`

## Workflows

- **Read a document**: `/pdf-viewer:view-pdf path/to/document.pdf`
- **Extract information**: After opening, ask questions about specific content
- **Summarize**: Request a summary of chapters or sections
- **Compare**: Open multiple PDFs for cross-referencing
